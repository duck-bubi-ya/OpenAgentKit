# apps/console — 管理端

适用于本目录。先读[根规则](../../AGENTS.md)、[架构](../../docs/architecture.md)及
[接口合同](../../docs/interfaces.md)；管理业务归属见 ADR-0025，组件准入见 ADR-0015。

## 职责与入口

- `src/lib/admin/`：AdminClient、管理 hooks、成员用量与 Operation 观察/恢复。
- `src/lib/api.ts`：运行时后端地址、管理员身份和客户端装配。
- `src/features/navigation/`：Browser History 路由、外壳、导航锁定与离页确认。
- `src/features/`：模版、资源、成员、用量、日志和品牌配置等页面业务。
- `src/lib/antd-theme.ts`、`src/styles.css`：antd token 及应用全局适配。
  页面模块的放置与现行流程见目录规则，不在本文件重复逐页规格。

## 不变量

1. 管理令牌按规范化后的完整 `apiBaseUrl` 隔离，仅发送到对应后端；
   不进 URL、history.state 或日志。切换服务不继承旧目标的令牌。
2. 初始化先读取并校验 `/api/config`；地址解析遵循宿主注入、查询参数及服务配置的既有顺序。
   初始化失败保留重试，不提前发送管理请求。
3. 管理业务留在本 app，通过公开 SDK Request、`/state` 与协议帧读取复用通用能力。
   不导入 SDK 私有实现，不向 SDK 添加固定管理路由或页面 hooks。
4. antd v6 服务于管理控件；对话、消息、审批卡及会话状态展示复用 kit-chat-ui。
   新代码按页面渐进收敛，不引入 `@ant-design/x` 或额外的通用组件体系。
5. 主题以唯一 `antdTheme` 配置为准，保留已有集中定制；不得假定管理端使用未定制的默认主题。
   全局浮层修正、CSS 变量镜像和应用内 kit token 适配归 `src/styles.css`；
   页面不散落颜色常量或覆盖 antd 内部样式。既有 Less 的维护边界见架构文档。
6. 确认弹窗可使用 antd Modal，必须模态、受管焦点、明确目标及显式确认。
   资源发布和限额调整展示差异；模版编辑/历史应用确认生效影响并通过 `base_version` 更新。
   模版上下架/删除按接口约定单次确认，后台计划和有效令牌保留；准备/重试成功不得自动执行。
   UI 确认不代表每个本地配置更新都有 SDK Plan 或确认令牌接口。
7. `auditor` 只读；UI 隐藏写入口并保留服务端权限校验，不能用按钮禁用代替权限控制。
   导入、详情预览或查询本身不创建资源、发布、上架或改变运行绑定。
8. 新建/编辑资源使用独立 YAML 批次；保留 revision、所有权及清理凭证。
   未修改的远端资源直接复用，修改后创建副本，不静默丢弃脱敏或不支持的字段。
9. 发布绑定与回执按完整成功证明解析。Operation 断流只恢复观察；
   部分成功、结果未知或中断不重发发布，收尾仅执行服务端 `recovery_action` 允许的动作。
10. 向导草稿、未保存输入和凭据只留当前页面；纯浏览不初始化批次。
    导航、刷新及离页遵守忙碌锁定和未发布内容确认，迟到请求不得覆盖新选择或跨目标清理。
11. 调试复用 `TemplateDebugPreview` 和既有 Session 合同，按管理员主体与用途隔离。
    自动清理仅覆盖本页面授权拥有的根调试 Session，仍走删除计划和令牌，
    不能推广到成员会话或其他管理员资源。
12. 显式 Agent 版本、运行时引用和模版 `base_version` 各自保留语义；
    历史展示元数据不能变成运行绑定，冲突不能通过自动刷新基线覆盖。

## 修改步骤

1. 先核对接口 op、共享 Schema、当前页面路由和状态所有者。
2. 管理调用经 `src/lib/admin/`，页面只编排业务；复用已有表单、资源选择和对话组件。
3. 行为变更同步接口或架构文档；文件移动同步目录规则，不把详细页面说明追加到本文件。
4. 按风险选择已有单测与 `apps/web/e2e/` 的管理端浏览器回归，
   覆盖权限拒绝、取消、失败重试及未知结果恢复等实际改变的路径。
